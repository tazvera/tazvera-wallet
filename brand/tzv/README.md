# Tazvera (TZV) · Official token logo

Use only these files. Do not redraw, stretch or recolour the logo.

| File | Use it for |
|------|-----------|
| `tzv-logo.svg` | Any size (vector). Best for websites, print, Canva |
| `tzv-logo-1024.png` | Large banners, press |
| `tzv-logo-512.png` | Exchanges, CoinGecko / CoinMarketCap listing forms |
| `tzv-logo-256.png` | Explorers, wallets (MetaMask, Trust Wallet) |
| `tzv-logo-128.png`, `-64`, `-32` | Small icons and lists |

All PNG files have a transparent background (nothing outside the circle).

## Design rules

- Shape: round coin. Thin green ring, black inside, green **T** in the middle (about 66% of the circle width).
- Colours: ring `#37DE64` · inside `#000000` · T gradient `#35E361` (top) to `#18923C` (bottom).
- Minimum size: 24 px. Below that, the T is not clear.
- Do not: put the T in a square, add text inside the coin, change colours, add shadows, or stretch it.
- The token name goes **below** the coin, never inside it: **TZV** (big) and **Tazvera** (small).
